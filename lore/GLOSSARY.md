# Glosario canónico

**CANON — términos bilingües.** Usar el término español en texto español y el inglés al referir la denominación original. No crear sinónimos técnicos adicionales; las denominaciones provisionales y límites se señalan.

| Término                                    | Definición y uso                                                                                                                                                  |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Threshold / Umbral                         | Región donde la Tierra se superpone con entornos ajenos. No sinónimo exacto de portal.                                                                            |
| Opening / Apertura                         | Manifestación de apertura asociada a la aparición de Umbrales; no especifica un mecanismo causal.                                                                 |
| The First Opening / La Primera Apertura    | Fenómeno histórico inicial. Distinto del nombre plural de la Era II, Las Primeras Aperturas.                                                                      |
| Convergence / Convergencia                 | Fallo progresivo de límites entre realidades y superposición espacial. Como desenlace: fusión permanente y adaptación de supervivientes.                          |
| The Threshold War / La Guerra del Umbral   | **PROVISIONAL CANON:** nombre del periodo central.                                                                                                                |
| Core / Núcleo                              | Estructura energética anómala desarrollada por una minoría humana tras exposición vinculada a Umbrales.                                                           |
| Awakening / Despertar                      | Estabilización del Núcleo y experiencia asociada.                                                                                                                 |
| Awakened / Despertado                      | Persona que ha experimentado el Despertar; no implica actividad de combate.                                                                                       |
| Hunter / Cazador                           | Denominación principalmente de Despertados que realizan combate o exploración. No clase ni sinónimo de Despertado.                                                |
| Capacity / Capacidad                       | Almacenamiento máximo de energía del Núcleo.                                                                                                                      |
| Flow / Flujo                               | Energía que el Núcleo puede manifestar simultáneamente.                                                                                                           |
| Affinity / Afinidad                        | Forma natural de expresión energética.                                                                                                                            |
| Resonance / Resonancia                     | Compatibilidad con energías, materiales, organismos, entornos o mundos.                                                                                           |
| Class / Clase                              | Manifestación funcional del Despertar: qué permite hacer.                                                                                                         |
| Rarity / Rareza                            | Lo inusual de una manifestación de clase. Especificar «rareza de Moment» al hablar del sistema V3, que es distinto.                                               |
| Rank / Rango                               | Magnitud/potencial detectado durante evaluación del Despertar, de E a SSS.                                                                                        |
| Beasts / Bestias                           | Término humano inicial e inexacto que agrupa seres diferentes; no taxonomía objetiva ni facción.                                                                  |
| Threshold Fauna / Fauna de Umbral          | Organismos ecológicos desplazados por Convergencia.                                                                                                               |
| Predators / Depredadores                   | Organismos especialmente peligrosos adaptados a regiones inestables.                                                                                              |
| Intelligent Peoples / Pueblos inteligentes | Civilizaciones no humanas con lenguaje, historia, sociedad e intereses propios.                                                                                   |
| Sovereign Beast / Bestia Soberana          | Denominación de amenaza extraordinaria empleada en el ejemplo de poder SSS. Clasificación y criterios precisos **TBD**; no presupone especie única ni jefe final. |
| Historical NPC / NPC histórico             | Identidad estable de la historia base, con destino variable entre vidas.                                                                                          |
| Personal NPC / NPC personal                | Persona del entorno de una vida cuya identidad puede variar; puede generarse desde pools controlados.                                                             |
| Moment                                     | Unidad significativa de gameplay narrativo. «Tarjeta» describe su presentación actual, no limita su duración o interacción futura.                                |
| Historical Footprint / Huella histórica    | Forma conceptual de describir contribuciones de una vida; no puntuación ni medidor moral implementado.                                                            |
| True Resolution / Resolución Verdadera     | Resultado último reservado; no se consigue solo mediante fuerza. «Final verdadero» remite a este concepto, no a otra categoría.                                   |
| Unknown / Desconocido                      | Estado del conocimiento sobre el destino humano; no un desenlace mundial adicional.                                                                               |

Los nombres de familias y clases se registran en [CLASSES](CLASSES.md); no cambiar nombres históricos de [HISTORICAL_NPCS](HISTORICAL_NPCS.md) al traducir. Para decisiones editoriales consultar [CANON_RULES](CANON_RULES.md).
