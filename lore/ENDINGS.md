# Finales y límites del conocimiento

**CANON.** Un final personal, un resultado mundial y lo que el personaje sabe son dimensiones distintas. Ningún rango garantiza una vida larga, buena o significativa. Contexto: [WORLD_HISTORY](WORLD_HISTORY.md).

## Categorías de desenlace mundial

| Categoría                              | Alcance aprobado                                                                                      |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Human Victory / Victoria humana        | La humanidad derrota o repele grandes fuerzas hostiles; no implica resolver la Convergencia.          |
| Pyrrhic Victory / Victoria pírrica     | La humanidad sobrevive con un coste enorme.                                                           |
| Stalemate / Estancamiento              | El conflicto continúa.                                                                                |
| Alliance / Alianza                     | Cooperación humana con una o más civilizaciones no humanas.                                           |
| Separation / Separación                | Las fronteras entre mundos se restauran o estabilizan con éxito.                                      |
| Exodus / Éxodo                         | La Tierra resulta insostenible y la humanidad se traslada.                                            |
| Convergence / Convergencia             | Los mundos se fusionan permanentemente y las civilizaciones supervivientes se adaptan.                |
| Extinction / Extinción                 | Desaparece la civilización humana. No añadir por inferencia una descripción biológica más específica. |
| True Resolution / Resolución Verdadera | **PRIVATE CANON — IMPLEMENTED IN TASK 14/14.1**. Contrato técnico público en docs/TRUE_RESOLUTION.md. |

Las ocho categorías ordinarias tienen implementación en Task 11; la novena en Task 14/14.1. Las condiciones del runtime son objetivos de implementación, no nuevas probabilidades canónicas. No imponer una fórmula o una jerarquía de mérito entre ellas.

«Convergencia» como desenlace designa la fusión permanente; como fenómeno designa el proceso de superposición. Victoria militar y resolución del fenómeno no son equivalentes.

## Muerte y conocimiento

El personaje solo sabe lo que pudo experimentar o aprender plausiblemente. Si muere antes de terminar la guerra, no obtiene automáticamente un epílogo omnisciente que le revele todo lo posterior.

Es válido mostrar **FATE OF HUMANITY: UNKNOWN / DESTINO DE LA HUMANIDAD: DESCONOCIDO**. No es otro resultado mundial: es falta de conocimiento sobre él. El futuro diseño debe separar información del mundo de información disponible para el personaje/jugador; no convertir metaprogresión en omnisciencia automática.

La vida personal puede ser satisfactoria aunque la humanidad pierda, o dolorosa y decisiva para una victoria. No juzgar su valor por bajas causadas, rango o desenlace global.

## Restricción de la Resolución Verdadera

**CANON:** fuerza de combate por sí sola no basta; SSS es insuficiente. La resolución eventual debe requerir comprender perspectivas múltiples. Una vida poderosa puede enseñar cómo ganar una guerra, una de investigación por qué existe, una civil qué cuesta, y una perspectiva no humana que nunca hubo un solo lado.

Esa formulación expresa propósito narrativo; no define una receta de clases obligatorias, número de partidas, pruebas coleccionables ni solución final.
